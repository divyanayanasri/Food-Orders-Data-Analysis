# Food Orders Data Analysis

## Project Overview
This project focuses on analyzing food ordering data using Python and Pandas. The objective is to examine the dataset, identify data quality issues, and prepare the data for further analysis.

## Objectives
- Understand the structure of the food orders dataset.
- Identify missing values and duplicated records.
- Check repeated Order IDs.
- Identify unexpected data types.
- Convert order and delivery timestamps into datetime format.
- Validate delivery timestamps against order timestamps.
- Perform data cleaning and preliminary analysis.

## Technologies Used
- Python
- Pandas
- NumPy (only if used in the notebook)
- Jupyter Notebook
